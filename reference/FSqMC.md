# Estimate Cohen's f-Squared and Generate the Corresponding Sampling Distribution Using the Monte Carlo Method

Estimate Cohen's f-Squared and Generate the Corresponding Sampling
Distribution Using the Monte Carlo Method

## Usage

``` r
FSqMC(object, alpha = c(0.05, 0.01, 0.001))
```

## Arguments

- object:

  Object of class `mc`, that is, the output of the
  [`MC()`](https://github.com/jeksterslab/betaMC/reference/MC.md)
  function.

- alpha:

  Numeric vector. Significance level \\(\alpha\\).

## Value

Returns an object of class `betamc` which is a list with the following
elements:

- call:

  Function call.

- args:

  Function arguments.

- thetahatstar:

  Sampling distribution of \\(f^2\\) (column `fsq`) and the local
  \\(f^2\\) (one column per regressor).

- est:

  Vector of estimates.

- fun:

  Function used ("FSqMC").

## Details

Cohen's \\(f^2\\) for the whole model, \\(f^2 = R^2 / (1 - R^2)\\), and
the local \\(f^2\\) of each regressor, \\(f^2_j = sr^2_j / (1 - R^2)\\),
where \\(sr_j\\) is the semipartial correlation, are derived from each
randomly generated vector of parameter estimates. Confidence intervals
are generated by obtaining percentiles corresponding to \\(100(1 -
\alpha)\\%\\) from the generated sampling distribution, where
\\(\alpha\\) is the significance level.

## References

Selya, A. S., Rose, J. S., Dierker, L. C., Hedeker, D., & Mermelstein,
R. J. (2012). A practical guide to calculating Cohen's f2, a measure of
local effect size, from PROC MIXED. *Frontiers in Psychology*, *3*, 111.
[doi:10.3389/fpsyg.2012.00111](https://doi.org/10.3389/fpsyg.2012.00111)

## Examples

``` r
# Data ---------------------------------------------------------------------
data("nas1982", package = "betaMC")

# Fit Model in lm ----------------------------------------------------------
object <- lm(QUALITY ~ NARTIC + PCTGRT + PCTSUPP, data = nas1982)

# MC -----------------------------------------------------------------------
mc <- MC(
  object,
  R = 100, # use a large value e.g., 20000L for actual research
  seed = 0508
)

# FSqMC -----------------------------------------------------------------
out <- FSqMC(mc, alpha = 0.05)

## Methods -----------------------------------------------------------------
print(out)
#> Call:
#> FSqMC(object = mc, alpha = 0.05)
#> 
#> Cohen's f-squared (fsq) and local f-squared
#> type = "hc3"
#>            est     se   R   2.5%  97.5%
#> fsq     4.1158 1.4375 100 1.8593 7.1580
#> NARTIC  0.9510 0.4182 100 0.1777 1.6831
#> PCTGRT  0.6019 0.2624 100 0.1105 1.1149
#> PCTSUPP 0.2909 0.2019 100 0.0282 0.7851
summary(out)
#> Call:
#> FSqMC(object = mc, alpha = 0.05)
#> 
#> Cohen's f-squared (fsq) and local f-squared
#> type = "hc3"
#>            est     se   R   2.5%  97.5%
#> fsq     4.1158 1.4375 100 1.8593 7.1580
#> NARTIC  0.9510 0.4182 100 0.1777 1.6831
#> PCTGRT  0.6019 0.2624 100 0.1105 1.1149
#> PCTSUPP 0.2909 0.2019 100 0.0282 0.7851
coef(out)
#>       fsq    NARTIC    PCTGRT   PCTSUPP

vcov(out)
#>               fsq     NARTIC      PCTGRT     PCTSUPP
```
