# Estimate Improvement in R-Squared and Generate the Corresponding Sampling Distribution Using the Monte Carlo Method

Estimate Improvement in R-Squared and Generate the Corresponding
Sampling Distribution Using the Monte Carlo Method

## Usage

``` r
DeltaRSqMC(object, alpha = c(0.05, 0.01, 0.001))
```

## Arguments

- object:

  Object of class `mc`, that is, the output of the
  [`MC()`](https://jeksterslab.github.io/betaMC/reference/MC.md)
  function.

- alpha:

  Numeric vector. Significance level \\(\alpha\\).

## Value

Returns an object of class `betamc` which is a list with the following
elements:

- call:

  Function call.

- args:

  Function arguments.

- thetahatstar:

  Sampling distribution of \\(\Delta R^{2}\\).

- vcov:

  Sampling variance-covariance matrix of \\(\Delta R^{2}\\).

- est:

  Vector of estimated \\(\Delta R^{2}\\).

- fun:

  Function used ("DeltaRSqMC").

## Details

The vector of improvement in R-squared (\\(\Delta R^{2}\\)) is derived
from each randomly generated vector of parameter estimates. Confidence
intervals are generated by obtaining percentiles corresponding to
\\(100(1 - \alpha)\\%\\) from the generated sampling distribution of
\\(\Delta R^{2}\\), where \\(\alpha\\) is the significance level.

## Examples

``` r
# Data ---------------------------------------------------------------------
data("nas1982", package = "betaMC")

# Fit Model in lm ----------------------------------------------------------
object <- stats::lm(
  formula = QUALITY ~ NARTIC + PCTGRT + PCTSUPP,
  data = nas1982
)

# MC -----------------------------------------------------------------------
mc <- MC(
  object = object,
  R = 100, # use a large value e.g., 20000L for actual research
  seed = 0508
)

# DeltaRSqMC ---------------------------------------------------------------
out <- DeltaRSqMC(object = mc, alpha = 0.05)

## Methods -----------------------------------------------------------------
print(x = out)
#> Call:
#> DeltaRSqMC(object = mc, alpha = 0.05)
#> 
#> Improvement in R-squared
#> type = "hc3"
#>            est     se   R   2.5%  97.5%
#> NARTIC  0.1859 0.0679 100 0.0442 0.2932
#> PCTGRT  0.1177 0.0562 100 0.0136 0.2230
#> PCTSUPP 0.0569 0.0318 100 0.0134 0.1272
summary(object = out)
#> Call:
#> DeltaRSqMC(object = mc, alpha = 0.05)
#> 
#> Improvement in R-squared
#> type = "hc3"
#>            est     se   R   2.5%  97.5%
#> NARTIC  0.1859 0.0679 100 0.0442 0.2932
#> PCTGRT  0.1177 0.0562 100 0.0136 0.2230
#> PCTSUPP 0.0569 0.0318 100 0.0134 0.1272
coef(object = out)
#>    NARTIC    PCTGRT   PCTSUPP 
#> 0.1858925 0.1176542 0.0568722 
vcov(object = out)
#>                NARTIC       PCTGRT       PCTSUPP
#> NARTIC   4.605450e-03 2.708872e-04 -3.484382e-05
#> PCTGRT   2.708872e-04 3.155103e-03  3.317709e-05
#> PCTSUPP -3.484382e-05 3.317709e-05  1.013640e-03
confint(object = out, level = 0.95)
#>              2.5 %    97.5 %
#> NARTIC  0.04416496 0.2931815
#> PCTGRT  0.01363412 0.2229883
#> PCTSUPP 0.01337168 0.1272339
```
